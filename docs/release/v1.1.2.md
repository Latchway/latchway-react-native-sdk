# Latchway React Native SDK 1.1.2

This patch preserves exact gateway URLs on React Native and includes the
corrected npm-only LatchwayChat example and LangChain integration guide.

The optional deprecated `/polyfills` entry and app-owned example now check
both `/v1/responses` and `/v1/chat/completions`. React Native's partial URL can
append a slash and cause `transport_destination_not_allowed`; the bootstrap
replaces only incomplete URL implementations. Complete host globals and fetch
are preserved. Destination validation is not weakened.

## Upgrade

```sh
npm install --save-exact @latchway/react-native@1.1.2
```

Recopy the application-owned `symbols.ts` and `polyfills.ts` files from the
versioned links in [the LangChain guide](https://github.com/Latchway/latchway-react-native-sdk/blob/v1.1.2/docs/langchain.md).
An npm update cannot change files previously copied into your app. Keep the
bootstrap first in the entrypoint and rebuild native dependencies as needed.
Deprecated helper users must still declare their optional peers explicitly.

Only `@latchway/client` and the private stream fallback are required runtime
dependencies. LangChain/Babel/global runtime setup stays app-owned. Native
iOS/Android pins remain 1.0.0; the native security boundary and wire protocol
are unchanged. Server 1.0.3 separately supports native/RN roots sharing an iOS
bundle or Android package with required direct attestation.

Runtime regressions exercise the actual pinned React Native URL implementation,
preservation of complete globals and fetch, streaming UTF-8 and cancellation.
This patch does not claim fresh native-device or production-distribution evidence.

The full repository `pnpm check` is not green: historical release-policy tests
still reference the CI/release workflows removed before this patch. Runtime
tests, lint, types and the 103 SDK unit tests pass; codegen, packaging and both
iOS/Android Metro checks also pass when run separately. These legacy failures are recorded, not suppressed,
and the existing simple publication workflow is retained.
