# Latchway React Native SDK 1.2.1

This patch fixes consumption of native Fetch response bodies on React Native
runtimes with an incomplete stream-backed `Response` implementation.

Normal OpenAI/LangChain calls, including `model.invoke()`, now read the actual
native response bytes when parsing HTTP 200 JSON. HTTP error bodies also remain
readable by framework error handling. A successful gateway request must not
become a client-side JSON parsing failure because the runtime treats a stream
as an ordinary response-body value.

The fallback supports `text()`, `json()`, `arrayBuffer()` and native streaming.
Binary `blob()` support depends on the host runtime; fallback `formData()`
supports URL-encoded bodies, not multipart. No global runtime polyfill is added.

Streaming and cancellation retain native-owned networking. There are no public
API, account-configuration, wire-protocol or required dependency changes.
JavaScript client 1.1.0, iOS 1.2.0 and Android 1.1.0 remain pinned; shared accounts
continue to require gateway 1.1.1+ and explicit shared-caller platform policy.

## Upgrade

```sh
npm install --save-exact @latchway/react-native@1.2.1
```

Keep the updated lockfile and regenerate the application's JavaScript bundle
through its usual build workflow. No changes to 1.2.0 configure/sign-in calls
or app-owned runtime files are needed for this fix. It does not require a
server deployment, native SDK upgrade or new attestation entitlement.

See [LangChain response handling and diagnostics](../langchain.md#response-handling-in-121)
for upgrade details and a redacted error-logging example. Do not automatically
retry a request merely because parsing failed: the upstream may already have
generated a response and incurred usage.

This is a JavaScript response-handling patch. Physical iOS/Android attestation
and production-distribution verification are separate; this release note does
not claim new device evidence.

## Patch verification

- 228 JavaScript tests, including 47 response/framework regressions using
  React Native's actual `whatwg-fetch`, OpenAI and LangChain implementations.
- 13 runtime/bootstrap tests, TypeScript checks, lint, contract/dependency
  compatibility checks, code generation and native-boundary checks.
- Production JavaScript bundles for both iOS and Android.
- Reproducible npm archives and a clean npm consumer with the released shared
  client; optional integration dependencies are not pulled into a core install.

The patch was isolated from unfinished source-breaking account/legacy cleanup.
No gateway deployment, quota reset, provider call or new device proof was part
of this release verification.
