# Latchway React Native SDK 1.3.0

Application sign-out now needs one call:

```ts
await app.signOut();
await yourAuth.signOut(); // Application-owned provider logout.
```

The native shared app handles an active account, pending sign-in, persisted
state after restart and unfinished retirement without requiring a current
account handle or generation ID. Pending identity completions cannot bring the
retired account back. Repeating `signOut()` retries unfinished cleanup; a real
secure-storage failure still rejects rather than reporting success.

Keep authentication transitions serialized and stop application-owned streams,
tools and UI callbacks before sign-out. Do not accept another login while
cleanup is incomplete. Native auth owners use the same shared app API—Swift
`try await app.signOut()` or Kotlin `app.signOut()` from a coroutine—even when
React Native or an AI feature has not been mounted. Latchway does not sign out
the external identity provider, reset quotas or log out other devices.

## Upgrade

- Install `@latchway/react-native@1.3.0`, update Pods and rebuild both native apps.
- Native pins are `Latchway/AppAttest` 1.3.0 and `dev.latchway` 1.2.0. Embedded
  hosts must resolve one matching native SDK implementation.
- JavaScript client 1.1.0, contract 1.1.0 and the React Native 0.74 / React 18.2
  minimum are unchanged. Android libraries continue to compile against API 34;
  the host's target SDK and other dependencies may require a newer toolchain.
- Native/RN may configure first; autolinking installs the native SDKs, with no
  extra runtime Latchway bootstrap or Firebase dependency.
- Existing account/generation-targeted logout APIs and the 1.2.1 Fetch response
  fix remain. This additive release does not remove compatibility migrations.

See [developer-supplied identity](../supplied-identity.md) and
[shared native apps](../shared-native-apps.md) for integration and cleanup retry
guidance. Publication does not establish fresh physical-device attestation,
Play distribution, cloud or cross-process extension evidence.
